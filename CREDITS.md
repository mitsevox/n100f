## Dolphin SDK

Each SDK file below holds what the target links of that object. Includes are reduced to `include/dolphin/`, and `// clang-format` markers and debug-only code are dropped. Asserts are dropped too, except in `OSThread.c`, `OSMutex.c`, `OSRtc.c`, `OSTime.c` and the `gx` files, which keep theirs at the upstream call sites. `include/dolphin/os.h` defines `ASSERTLINE`, `ASSERTMSGLINE`, `ASSERTMSG1LINE` and `ASSERTMSG2LINE` as `((void)0)` outside a DEBUG build. No other kept assert changes a byte.
