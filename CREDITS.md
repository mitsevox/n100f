## Dolphin SDK

Each SDK file below holds what the target links of that object. Includes are reduced to `include/dolphin/`, and `// clang-format` markers and debug-only code are dropped. `src/rwsdk/` is written for this project from the target's disassembly. No Criterion RenderWare source is used. Its structure layouts follow the SLUS-20349 DWARF in `references/` where it has the type, and otherwise the target's own accesses. The function names it adds come from the PS2 June 2001 prototype symbol table in `references/` (the static helper names `ExecuteNode`, the six generic pipeline helpers in `bapipew.c`, the heap helpers in `p2heap.c` (`_rxHeapGrow`, `_rxHeapReallocLarger` and the inlined free-block, superblock, allocation and reallocation helpers) and `_msbitpos` and `_insertionsort` in `p2resort.c` come from the PS2 January 2001 prototype's symbol table there) and, where the prototype lacks them (the GameCube-only clump functions, `WorldInitClumpExt`, `WorldObjectOpen`, `RwMatrixOptimize`, `RpAtomicGetWorldBoundingSphere` and the six geometry and world-sector native stream functions), and `_rpWorldPipelineOpen` and `_rpWorldPipelineClose`, bfbb's underscored spelling of the June prototype's `rpWorldPipelineOpen` and `rpWorldPipelineClose`), from bfbb's `config/GQPE78/symbols.txt`; the data names (`RwEngineInstance`, the module and plugin-registry objects including `rasterModule`, `imageModule` and `imageTKList`, the clump extension offsets, `defaultSurfaceProperties`, `MatFXInfo` and the MatFX data offsets, the `lastSeen` rights words, `_RpDlVtxFmtDefault`, `_RpVtxFmtModule`, the vertex-format plugin offsets and the pipeline data `RxPipelineInstanced`, `_rxHeapGlobal`, `_rxHeapInitialSize`, `_rxPipelineMaxNodes` and `_rxExecCtxGlobal`) come from bfbb's `config/GQPE78/symbols.txt` at the revision above. Type, member, typedef, macro and parameter names the DWARF does not have come from bfbb's `include/rwsdk/rwplcore.h` and `include/rwsdk/rpworld.h` at the same revision, which are derived from the RenderWare SDK headers; with the project owner's approval, identifier names (and layouts checked against the target's accesses) are taken from them, as related names. No RenderWare function code, comments or other header text is copied into `src/rwsdk/`; the SDK macro bodies and enums copied into `include/` are listed above. The file-local module data, clump and world-object extensions, ties, sector search and resource-heap types use this project's own names ([libraries](docs/libraries.md#renderware-sdk-names-and-headers)).
